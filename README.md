# Infynova Group — Premium Political Consulting Landing Page

Standalone responsive HTML landing page for Infynova Group.

## Included
- User-provided Infynova Group logo embedded directly in `index.html` (self-contained)
- Premium dark/navy visual system with electric-blue accents
- Responsive navigation, hero, services, process, capabilities, insights and consultation sections
- Smooth scrolling and lightweight CSS/JS reveal animations
- WhatsApp CTA and consultation form UI
- No fabricated client results, testimonials, logos, statistics or case studies

## Run
Open `index.html` directly in a browser. The logo is embedded, so it does not depend on the `assets` folder.

For production deployment, connect the consultation form to a secure backend/form provider.
